# MemoBooks UI 개선 · 2026-11-26

## 방향

월 지출과 빠른 기록을 중심으로 정보 순서를 정리한다. 남색 요약 카드, 파란색 주요 동작,
분류별 아이콘 색상, 시스템 글꼴과 의미 기반 배경을 사용한다. 거래 저장·계산·AI·백업 형식은 바꾸지 않는다.

## 참고

- https://help.copilot.money/en/articles/6045480-dashboard-tab-overview : 지출·예산과 거래를 한 화면에서 확인하는 정보 구성.
- https://www.copilot.money/dispatch/transaction-summary-improvements : 분류 색상을 일관되게 사용해 거래를 구분하는 방식.

별도 브랜드의 화면·아이콘·에셋을 복제하지 않고 기존 SwiftUI 구성 요소를 개선했다.

## 적용

- 홈: 소개 문구 축소, 월 지출·수입·기록 차액·예산 통합, 기록 버튼, 최근 거래 6건.
- 기록: 작은 제목과 간결한 안내, 적당한 크기의 입력창, 강조한 음성 입력, AI 처리·실패·저장 전 확인 유지.
- 공통: 분류별 아이콘 색상, 거래 행 글자·여백, 파란색 강조, 다크 모드에서 흰 글자가 읽히는 달력 선택 배경.
- 달력·설정·첫 사용 안내와 워치 버튼에도 같은 방향의 색상 적용.

화면의 거래는 --demo 메모리 저장소의 가상 데이터이며, 실제 사용자 기록을 캡처하지 않는다.

## 확인

- 기존 로직·비동기 백업·Watch 요청/발신함·SwiftData 검사 통과.
- Debug / Release iPhone 및 포함된 Watch 시뮬레이터 빌드 통과.
- 별도 시뮬레이터에서 홈·기록·달력·내역·설정 캡처, 다크 달력 및 큰 글씨 홈 확인.
- 실제 기기에서 새 UI의 전체 터치 흐름·VoiceOver는 미검증.
