개인정보처리방침

시행일: 2026년 11월 28일 · 대상: 메모가계부(MemoBooks) iPhone·Apple Watch 앱

운영자 Dalzoo03는 앱에 자체 서버, 계정, 광고·분석 SDK 또는 외부 AI API를 사용하지 않습니다. 앱 이용을 위해 이름·이메일·은행 계좌를 등록할 필요가 없습니다.

1. 기기에 저장하는 정보와 목적

  • 거래 금액·유형·분류·메모·날짜·기록 식별자: 가계부 표시·집계·수정·중복 저장 방지에 사용합니다.
  • 예산·설정·작성 중인 문장·백업 시점: 설정 유지와 입력 복구에 사용합니다.
  • 워치 대기 메모·분석 결과·요청 식별자: 연결 복구와 확인 후 저장을 위해 해당 기기에 보관합니다.

이 정보는 앱의 기기 내 저장소에 보관합니다. 개발자가 이를 수신하거나 원격으로 열람하는 기능은 없습니다.

2. AI와 마이크·음성인식

거래 분석은 연결된 iPhone의 Apple Foundation Models 온디바이스 모델로 수행합니다. 외부 OpenAI·Claude API로 거래를 전송하지 않습니다. AI 모델 준비 후에는 인터넷 없이 거래 분석이 가능합니다.

앱 내 마이크는 사용자가 실행할 때 마이크·음성인식 권한을 요청하며, 기기 내 한국어 Speech 인식을 지원하는 경우만 사용합니다. 앱은 녹음 파일을 별도로 저장하지 않습니다. 변환된 문장은 작성 중인 입력이나 거래 메모로 보관될 수 있습니다.

키보드 마이크와 Apple Watch의 시스템 받아쓰기는 Apple이 제공하는 기능입니다. 해당 OS 설정과 Apple 정책을 따르며 네트워크를 사용할 수 있습니다. iPhone 설정에서 권한을 철회해도 직접 입력은 가능합니다.

3. 기기 간 전달과 백업 파일

워치에서 확인·분석을 요청한 메모와 결과는 WatchConnectivity를 통해 페어링된 iPhone과 주고받습니다. 이는 개발자 서버 전송이 아닙니다. iPhone에서 저장한 모든 거래가 워치에 자동 동기화되는 기능은 제공하지 않습니다.

JSON·CSV 내보내기를 선택하면 거래가 사용자가 지정한 위치로 복사됩니다. iCloud Drive 등 외부 저장 위치를 선택하면 해당 서비스의 정책이 적용됩니다. OS의 기기 백업·복원은 사용자 설정과 Apple 정책을 따릅니다.

4. 보관 기간과 삭제 방법

  • 저장한 거래: 내역에서 해당 행을 왼쪽으로 밀고 삭제를 선택하여 지울 수 있습니다. 앱을 기기에서 삭제하면 해당 기기의 앱 저장소도 삭제됩니다. 앱 정리하기(오프로드)는 앱 삭제와 다릅니다.
  • 작성 중인 입력: 입력창의 ‘비우고 새 기록’으로 비우거나, 저장 완료 시 해당 입력을 지웁니다. 워치에 보관된 대기 메모는 별도로 남을 수 있습니다.
  • 워치 대기 메모: 저장 완료 응답 후 대기 목록에서 제거됩니다. 앱 데이터 전체를 제거하려면 iPhone 앱과 Watch 앱을 각 기기에서 별도로 삭제해야 합니다.
  • 내보낸 파일과 OS 백업: 앱에서 거래를 삭제하거나 앱을 삭제해도 별도 사본은 자동 삭제되지 않습니다. 파일 앱, 공유받은 위치 및 OS 백업 설정에서 직접 관리해야 합니다.

개발자는 기기에 있는 거래를 원격으로 조회·복구·삭제할 수 없습니다. 앱 삭제 전 필요한 데이터를 백업하세요.

5. 지원 문의와 웹사이트

이 안내 페이지는 GitHub Pages에서 제공합니다. 페이지 접속과 GitHub Issues 문의에는 GitHub의 개인정보처리방침이 적용되며 접속 정보나 직접 작성한 문의 내용이 해당 서비스에서 처리될 수 있습니다. 이 웹사이트에는 별도의 분석 코드·광고·문의 수집 폼을 넣지 않았습니다.

문의는 지원 페이지에서 할 수 있습니다. GitHub Issues는 공개되므로 실제 거래 내역, 음성, 이름, 계좌번호, 백업 파일 등 개인정보를 올리지 마세요. 문의로 제공한 내용은 문제 확인과 답변에 사용하며, GitHub 내 게시물의 수정·삭제 기능을 통해 관리할 수 있습니다.
